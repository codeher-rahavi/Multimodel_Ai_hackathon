# AI-Powered Smart Study Platform

An interactive study platform designed to help students organize learning materials, track their academic progress, identify weak topics, and improve their learning experience through AI-assisted study features.

## 🚀 Features

- **Dashboard** – View study progress, recent quizzes, weak topics, and learning recommendations.
- **Study Materials** – Access a dedicated section for organizing study resources such as PDFs, presentations, and videos.
- **AI Tutor** – A dedicated interface for AI-assisted learning and academic support.
- **Quiz and Progress Tracking** – Review quiz activity and monitor learning progress.
- **Personalized Recommendations** – Discover topics that may need additional attention based on study activity.

## ⚙️ Installation and Setup

### Prerequisites

- Node.js and npm installed on your computer
- Git (optional, for version control)

### Steps

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually `http://localhost:5173`.
